SCIC - TRIE (busca por prefixo) - dados inteiramente simulados
Base carregada: 180 registros.
Chaves distintas indexadas: 12 (nomes de módulos + códigos hexadecimais de sensores).
Caracteres somados das chaves: 73; nós criados na trie: 70 (a diferença é o prefixo compartilhado).

Código do sensor em decimal e em hexadecimal (a chave usada na trie):
  Agricultura: 176 (decimal) = B0 (hex)
  Comunicação: 192 (decimal) = C0 (hex)
  Dados: 240 (decimal) = F0 (hex)
  Habitação: 160 (decimal) = A0 (hex)
  Laboratório: 208 (decimal) = D0 (hex)
  Suporte Médico: 224 (decimal) = E0 (hex)

Busca 'com': 30 registro(s); ids: 3, 9, 15, 21, 27 ...; módulos: Comunicação
Busca 'COMUNICAÇÃO': 30 registro(s); ids: 3, 9, 15, 21, 27 ...; módulos: Comunicação
Busca 'lab': 30 registro(s); ids: 4, 10, 16, 22, 28 ...; módulos: Laboratório
Busca 'su': 30 registro(s); ids: 5, 11, 17, 23, 29 ...; módulos: Suporte Médico
Busca 'c0': 30 registro(s); ids: 3, 9, 15, 21, 27 ...; módulos: Comunicação
Busca 'd': 60 registro(s); ids: 4, 6, 10, 12, 16 ...; módulos: Dados, Laboratório
Busca 'xyz': 0 registro(s); ids: -; módulos: -
Busca '' (vazio): 180 registro(s); ids: 1, 2, 3, 4, 5 ...; módulos: Agricultura, Comunicação, Dados, Habitação, Laboratório, Suporte Médico

Observações:
  - A busca ignora acentos e maiúsculas: "com" e "COMUNICAÇÃO" vêm da mesma chave "comunicacao".
  - Um prefixo curto pode casar com nome de módulo e com código hexadecimal ao mesmo tempo
    (ex.: "d" casa com o módulo Dados e com o código D0); cada id aparece só uma vez.
  - Prefixo inexistente retorna lista vazia; prefixo vazio retorna todos os ids.
